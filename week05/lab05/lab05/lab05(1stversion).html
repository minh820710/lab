I. HTML5 Basic Elements

1. Layout elements

Element Purpose
"header" Banner or introduction at the top
"nav" Group of navigation links
"main" The main of content of the page(use once)
"section" A themed group of content, usually with a heading
"article" A self-contained piece, like a blog post
"asisde" Side content
"footer" Bottom of the page or section

2. Lists element

Element Purpose
"ul" Unordered list
"ol" Ordered list
"li" An item in a "ul" tag or "ol" tag
"dl", "dt", "dd" Definition list: the list, the term, the description

3. Tables element

Element Purpose
"table" The table
"caption" The table's titile
"thead", "tbody", "tfoot" Header, body and footer groups of rows
"tr" A row
"th" A header cell
"td" A normal data cell

II. Headings and Paragraphs

Headings and paragraphs are BLOCK elements

1. Headings

There are 6 levels of heading. Headings are logical marked. Do not skip levels. If you want to change the size of a heading, don't change its level - change the CSS.

2. Paragraphs

Paragraphs contain the body text of a web page. You cannot put another block element inside a paragraph.

III. Special Characters

While HTML supports many named special characters like ® (#174), XML only supports 5 namely: " ' & < and >. So to keep you HTML compliant you need to use numbers for all the others.
